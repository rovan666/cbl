从零到完全掌握

8 课互动教程：每一课都能动手点、动手跑、当场自测。所有演示数据由真实编译器生成。
使用方法：按顺序学，每课做完「动手实验」再点底部的「我学完了这一课」；全部完成后进第 7 课综合考察。
先弄明白

「完全掌握」= 四层：会用（空手写出新场景的 .cbl）、会讲（任意一行代码能说出为什么）、 会改（新需求 20 分钟改完且测试全绿）、会答（答辩追问接得住）。本教程的每个环节都在为这四层服务。

学习建议

  • 顺序：0 → 1 → 2 → … 每课都假设你学过前面的。
  • 动手大于阅读：绿色「动手实验」卡片一个都不要跳过；看十遍不如做一遍。
  • 交叉互讲（4 人小组）：学完自己负责的课后，去给队友讲一遍别人的课——讲不清的地方就是没掌握的地方。
  • 复习：每课末尾的自测题和第 7 课的抽测可以反复刷，进度存在浏览器本地。
